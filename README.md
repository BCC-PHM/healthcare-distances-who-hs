# Healthcare Distances (WHO Healthy Cities)

Estimating average distance between homes of Birmingham residents and their nearest:
- Hospital/Emergency Care 
-	Urgent treatment centre (UTC)
-	Walk-in/General Practitioner
-	Pharmacy
